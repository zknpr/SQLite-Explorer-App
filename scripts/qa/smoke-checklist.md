## OS integration (57-67) — BUNDLE ONLY. Every step here rides a path the OS delivers, and **none of them can be tested with `cargo run`**: a bare binary is not LaunchServices-registered, so it never receives Apple Events or document-open events at all and will appear to "pass" by doing nothing. Three real defects hid behind exactly that gap until a bundle was driven (2026-08-18). Build `npm run tauri build -- --debug` and drive `src-tauri/target/debug/bundle/macos/SQLite Explorer.app`. Fast iteration without a full rebundle: `cargo build --features tauri/custom-protocol`, then copy the binary over `…/SQLite Explorer.app/Contents/MacOS/sqlite-explorer-desktop`.
